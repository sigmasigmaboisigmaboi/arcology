# Arcology

Society has retreated into massive, fully automated megastructures known as **Arcologies**.

Inside **Arc-09**, life is hyper-monitored, optimized, and sterile. Conception is handled via AI incubators, and physical human connection has become obsolete. 

Driven by forbidden historical logs about an obsolete concept called **"love"**, a lonely resident attempts to break the cycle of cold isolation and find a genuine human bond.

Play through a **14-day loop** balancing corporate quotas, daily survival, and a dangerous search for real connection in a silent tower.
